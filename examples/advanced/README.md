# Advanced examples

These examples intentionally show lower-level or specialized Conflux APIs:
runtime work pools, explicit offload, protocol experiments, manual JSON
mapping, observability policy stacks, database primitives, process execution,
templates, and crypto utilities.

Start with `examples/quickstart/` or the top-level HTTP examples when learning
the public app facade. Use this directory when you need to customize internals
or inspect lower-level building blocks.
