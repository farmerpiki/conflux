# Conflux Examples

Use the examples in this order:

1. `quickstart/` shows the shortest path for new services using `import conflux;`.
2. `public/` is the cookbook surface for common HTTP, static file, SSE, middleware, compression, forms, and client tasks.
3. `advanced/` contains production and integration proof points: lifecycle, observability, policy stacks, explicit offload, JSON providers, templates, file I/O, work coordination, database, and HTTP/3.

The quickstart examples should stay small and copyable. Public examples should use the curated facade unless a feature-specific import is the point. Advanced examples may show lower-level APIs when they demonstrate an explicit cost, lifetime, provider, or integration boundary.
